Project data and source links

How to share this app

  1. Share the ZIP project with a friend, or host the folder using GitHub Pages / Netlify to get a shareable web link.
  2. For Android installation, open the hosted HTTPS link in Chrome and choose Install app / Add to Home screen.
  3. Export your JSON data to transfer your trackers. Local browser data does not automatically sync between phones.
